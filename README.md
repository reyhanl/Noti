# Noti

Noti is a simple yet versatile note-taking application designed to help you organize your thoughts, ideas, and tasks effortlessly.

## Features

- **Text Formatting**: Easily format your text with options for bold, italic, and color.
- **Image Support**: Insert images directly into your notes to add visual context.
- **Easy to Use**: Intuitive interface for seamless note-taking experience.
- **Customization**: Personalize your notes with various font styles and colors.
- **Save and Edit**: Noti uses CoreData to save your data offline.

## Instalation Guide

git clone https://github.com/reyhanl/Noti.git
